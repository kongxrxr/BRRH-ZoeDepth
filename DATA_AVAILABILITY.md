# Data and Code Availability

The experiments use public KITTI and NYU Depth V2 datasets under their respective dataset terms.

## Datasets

This repository does not redistribute KITTI or NYU Depth V2 data.

Users should obtain the datasets from their official sources and arrange them according to the local paths expected by the training/evaluation scripts.

## Code

This release package contains the model code, training scripts, evaluation scripts, manuscript source, and verification reports needed to inspect the BRRH-ZoeDepth implementation.

## Checkpoints and Logs

Large checkpoints and full training logs are not included in the repository by default. They can be released separately through GitHub Releases, cloud storage, or supplied by the corresponding author upon reasonable request.
